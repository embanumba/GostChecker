# GostChecker
Ии-система для проверки оформления ВКР по требованиям ГОСТ 7.32-2017 

Сервис использует предобученную ИИ-дель ResNet18 для обучения её требованиям к оформлению работ. 

Основные критерии проверки:
* поля
* междустрочный интервал
* размер шрифта
* тип шрифта
* выравнивание текста
* оформление заголовков
* оформление списков
* оформление содержания

Титульный лист проверяется только по критериям шрифта, интервала, выравнивания и полей. 

Необходимый датасет для обучения модели должен содержать от 500 изображений по двум основным категориям
*train - основной датасет, содержащие изображения на которых отображены верные и неверные оформления документов.
* val - дополнительный датасет, на котором обученная модель показывает результаты обучения.

Если по вычисления зависимость вырастет на датасет val вырастет, в сравнении с train, это будет переобучение модели, а следовательно проблема в датасете.

Для обучения папка train должна содержать 100 изображений, папка val около 150 изображений.
